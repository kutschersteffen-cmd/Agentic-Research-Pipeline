# Notes

Decisions written by people. Where a note and the OpenWiki pages in `openwiki/` disagree, the note wins.

- One note per decision, one Markdown file each, named after the decision (`grounding-threshold.md`).
- Say what was decided, why, and the date. Keep it short; link instead of repeating.
- Link the files or wiki pages a note is about by their repo-relative path in double square brackets,
  for example [[backend/arp/grounding.py]]. Obsidian (repo root opened as a vault) and the Atlas page
  both follow these links.
- Edit notes in Obsidian or by PR. Agents read them but don't write them unless asked.
