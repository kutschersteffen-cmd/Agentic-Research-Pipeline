# Label review: water_scarcity_exposed

Research pass 2026-11-02, verified against the web the same day. SEC filers point to the primary document of their latest 10-K/20-F from EDGAR (located via the EDGAR submissions API). Each filing's full text was searched for "water scarcity", "water stress", "water shortage", "water availability", "water supply", "drought" and "arid"; rationale quotes come from those hits. Heidelberg Materials uses its 2025 annual and sustainability report PDF (ESRS E3 section searched the same way).

`exposed_undisclosed` cases were labelled only where that search found no hits, or only a generic natural-disaster or climate list that does not name water scarcity as a risk to the company. Each has two label sources: the company filing (Item 2 / properties for site locations) and a public water-stress source for the region (WRI Aqueduct via press coverage, ADWR, WRI US analysis, or reporting on regional drought emergencies). Site-to-basin matching was done from general knowledge of each company's plant locations, not plant-by-plant against the Aqueduct map. ISINs were filled from memory only where confident; LEIs are left out. `fiscal_year` is taken from the filing's period-end date (a period ending January to March counts as the previous year).
