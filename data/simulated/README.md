SIMULATED DATA. Not real ESG data. Generated by arp showcase simulate.

Every value in `esg_simulated.csv` is an invented, sector-based estimate for a demo. No number here is a
real company's real figure, and the ranges below are illustrative, not sourced. Each row carries
`data_status` = `simulated`.

| File | What it is |
|---|---|
| `esg_simulated.csv` | The dataset: one row per ISIN of the equity lines in `data/holdings/*.xlsx`, sorted by ISIN. Written by the command; do not edit by hand. |
| `activity_overrides.csv` | Hand-kept input (`isin,name,activity,share,reason`): companies whose business is a controversial activity. `isin` and `name` are copied from a holdings file. |

Regenerate (from the repo root or from `backend/`; the same input always gives the same bytes):

```
arp showcase simulate [--holdings-dir data/holdings] [--overrides data/simulated/activity_overrides.csv] [--out data/simulated/esg_simulated.csv]
```

Spec: `docs/superpowers/specs/2026-11-12-showcase-portfolio-data-design.md`. The tables below are copied from it.

## Rows and companies

One row per distinct ISIN over rows whose `Type of Security` is `Aktien`, `Equities`, `Depository Receipts`
or `Preferred Stock`. Rows with weight `N/A` are kept.

A key is the `Name` (upper-cased, stripped) + the country in English. A company is the set of keys linked by
a shared ISIN. Every ISIN of a company gets identical values in every column except `isin`, `company_id`,
`files`. Name, country and sector are the company's, taken from its first line in the file order
`MSCI_World`, `SP500`, `MSCI_Europe`, `MSCI_EM`, `AI_Big_Data`, `EURO_STOXX_50`, `DAX`. Every draw is seeded
from SHA-256 of the company's first key.

## Columns

Decimals: tCO2e and EUR M values 2; `climate_carbon_intensity`, `ghg_intensity`, revenue shares,
`green_revenue_pct` and `transition_score` 4; `climate_green_revenue_pct`, the E, S, G scores, `esg_score`,
`esg_trend` and `lct_score` 2.

| Group | Columns |
|---|---|
| Identity | `isin`, `company_id` (`isin_<ISIN>`), `name`, `country` (English), `sector` (peer group), `files` (file stems, `;`-joined), `data_status` (always `simulated`) |
| Climate (the ESG upload's seven) | `climate_scope1_tco2e`, `climate_scope2_tco2e`, `climate_scope3_tco2e`, `climate_carbon_intensity` (tCO2e per EUR M revenue, scope 1+2), `climate_evic_eur_m`, `climate_revenue_eur_m`, `climate_green_revenue_pct` (percent 0 to 100) |
| ESG scores (0 to 10) | `esg_e_score`, `esg_s_score`, `esg_g_score`, `esg_score` (mean of the three), `esg_trend` (0.80 to 1.20), `controversy_level` (integer 0 to 5) |
| Revenue shares (fractions 0 to 1, Index Construction's convention) | `coal_revenue_pct`, `oil_revenue_pct`, `gas_revenue_pct`, `high_intensity_power_revenue_pct`, `tobacco_revenue_pct`, `weapons_revenue_pct`, `alcohol_revenue_pct`, `gambling_revenue_pct` |
| Flags (`true`/`false`) | `controversial_weapons`, `norms_violation`, `severe_controversy` (`controversy_level` = 5) |
| Transition | `ghg_intensity` (= `climate_carbon_intensity`), `green_revenue_pct` (= green percent / 100), `transition_score` (0 to 1), `lct_score` (0 to 10), `lct_category`, `transition_grade` (`A` to `F`), `transition_grade_label` |

## Size

Weight = the sum of the company's `Weighting` values in the first of the indices below holding it with a
numeric weight, as a fraction. Market cap (EUR M) = weight × that index's assumed market cap. A company with
no numeric weight there (AI-only, or `N/A`) gets the median market cap of its peer group's other companies.
`climate_evic_eur_m` = market cap × EV factor; `climate_revenue_eur_m` = EVIC / EV-to-sales.

| Index, in lookup order | Assumed market cap (EUR M) |
|---|---|
| MSCI World | 75,000,000 |
| MSCI EM | 8,500,000 |
| MSCI Europe | 14,000,000 |
| S&P 500 | 52,000,000 |
| EURO STOXX 50 | 4,800,000 |
| DAX | 1,900,000 |

## Transition grade

Per peer group, over its n companies, with values as written in the file:

1. `transition_score` = 0.5 × (1 − intensity percentile) + 0.3 × green-share percentile + 0.2 × `esg_e_score`
   / 10. A percentile is (rank − 1) / (n − 1), rank by ascending value, ties take the lowest rank, 0 when
   n = 1. `lct_score` = 10 × `transition_score`.
2. Sort companies by `transition_score` descending, ties by the company's smallest ISIN ascending; position
   r of n gets the grade below. Every ISIN gets its company's grade.

| Grade | Label | Position r of n | Share of the peer group |
|---|---|---|---|
| A | Leader | r ≤ floor(0.10 n) | 10 % |
| B | Credible | r ≤ floor(0.30 n) | 20 % |
| C | Gaps | r ≤ floor(0.60 n) | 30 % |
| D | Emerging | r ≤ floor(0.85 n) | 25 % |
| E | Not credible | r ≤ floor(0.95 n) | 10 % |
| F | Disqualified | the rest | 5 % |

`lct_category`: green percent ≥ 50 → `solutions`; else Utilities, Energy, Materials with grade D, E or F →
`asset_stranding`, with A, B or C → `operational_transition`; else Industrials and Consumer Discretionary
with `climate_carbon_intensity` above the median over the peer group's companies → `product_transition`;
else `neutral`.
