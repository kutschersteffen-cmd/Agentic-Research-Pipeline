# Files

- [Data-point extraction engine](extraction.md) - How backend/arp/extraction turns a released data-point schema into one grounded, checked and routed value per company, field and period. Covers reuse by input hash, the XBRL tagged-value shortcut, the LangGraph extract, verify, adjudicate and aggregate graph, how aggregation applies grounding, record checks, three-way routing (auto_accept, review, hold) and derived fields.
- [Citation grounding](grounding.md) - How backend/arp/grounding.py checks every model-reported quote against the cited document's real text (exact, then normalised, then fuzzy, with strict rules for short and numeric quotes), restricts matches to the passages the model saw, resolves page, sheet, table and character offsets from the verified match only, and where the same check is reused in extraction, review and publishing.
- [Publishing facts](publish.md) - How backend/arp/publish turns a finished extraction run into versioned, effective-dated published facts. Covers candidate selection from routes and final review decisions, the lineage gate on archived originals, one release per document, the version plan (insert, reconfirm, older), the outbox of fact events, withdrawal that restores earlier values, as-of reads, the internal_only licence refusal, the daily re-grounding job, and the API and CLI.
