# ARP brand

Colours, type and components live in [`DESIGN.md`](../DESIGN.md). This file covers the mark only.

## Mark: Pixel A

A letter A built from ten squares. The apex is the brand colour: orange (#ea4c14) on light grounds,
turquoise (#2ee6d6) on dark grounds. It marks where a person ratifies what the agents proposed.
The brand colours live only in the apex; the interface's "needs a person" signal is amber (see
DESIGN.md, The Brand Colour Rule).

| File | Use |
|------|-----|
| `docs/brand/arp-mark.svg` | Light grounds (ink + brand orange) |
| `docs/brand/arp-mark-night.svg` | Dark grounds (ink + brand turquoise) |
| `docs/brand/arp-lockup.svg` | Lockup for light grounds: "ARP" spelled on the mark's grid |
| `docs/brand/arp-lockup-night.svg` | Lockup for dark grounds |
| `frontend/public/favicon.svg` | Favicon, switches with system theme |

## Lockup sizes

- **Landing page:** the large animated lockup.
- **App sidebar:** the lockup at 32px high. It is the first thing in the sidebar.
- **Favicon and small uses:** the mark alone, never below 16px high.

## Lockup

The lockup spells "ARP" in the mark's own style: each letter is a 5 × 5 grid of 10-unit squares
with 2-unit gaps, letters one empty column apart (206 × 62 units). The A is the mark itself, so
its apex is the lockup's one coloured pixel; R and P are all ink. Use the SVG files; never set
"ARP" as live text next to the mark, and never colour a second pixel. Below 24px high, use the
mark alone.

## Rules

- Ink everywhere except the apex square. Never recolour the other squares or change the grid.
- Square geometry, no rounding, no shadows, no gradients on the mark itself. Its square is the
  marker of the interface (DESIGN.md, Pixel Mark Language).
- Clear space: one square (10 units) on all sides. Minimum size 16px high; the grid stays legible down to 16px.
- On a coloured or photo ground use the single-colour version: all ink or all white, apex included.
- Do not use the brand colours anywhere else, in the mark's neighbourhood or in the interface.

## Voice

Plain and exact, like the interface: "Agents propose; people ratify." Say what a run did and what
waits on whom. No hype words.
