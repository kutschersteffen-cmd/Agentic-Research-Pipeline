Architecture · Agentic Research Pipeline

How the repo fits together

The browser and the CLI both drive the same Python package, backend/arp. Its agent pipelines call Claude to plan and deterministic code to compute, re-check every citation against the source text, and store everything in Postgres. Anything a pipeline proposes waits in the review queue until a person decides.

Optional services in docker-compose.yml, not drawn: OpenSearch (full-text search), MinIO (object storage for document blobs) and Superset (BI dashboards over the bi views in Postgres).
