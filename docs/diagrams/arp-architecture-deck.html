Architecture overview

Agentic Research Pipeline

Agent pipelines for investment research at scale: thematic universes, cited data extraction and portfolio analysis, for up to about 4,000 companies per run.

02 · System

Two clients drive one Python package

The UI and the CLI both reach the agent pipelines. Results land in Postgres; proposals wait in the review queue for a person.

03 · Workspaces

Five workspaces hand work to each other

Templates, indicators and alerts flow left to right. Every workspace reads issuers from Data Hub’s security master.

04 · Tech stack

One stack underneath every workspace

The LLM plans, deterministic code computes, and every citation is re-verified against its source.

05 · Workspace 1 · R&D Lab

Spot themes, test strategies, build indices

Claude argues for, against and judges each company match; contested matches go to review before scoring.

06 · R&D Lab · Spot

Emerging themes surface from filings and news

Claude tags mentions; clusters are compared with last week. Only new themes with 2+ sources and corporate action are written up, and a person promotes or rejects each.

07 · R&D Lab · Define

A taxonomy is a DRAFT until a person ratifies it

Nine derivation methods; merges, standards mapping, hand edits and the Taxonomy Researcher each add a new DRAFT version.

08 · R&D Lab · Match

Every company and activity goes through the same graph

A found revenue share is banded directly; otherwise Claude argues for, against and judges. Arbitration sends disagreements to review.

09 · R&D Lab · Score

Decision Studio scores with rules, not a model

Gates resolve before averaging and a sufficiency check comes first. Only a ratified, complete version can publish, and a snapshot is write-once.

10 · R&D Lab · Construct

Index construction reads only approved, dated inputs

An approved calibration in force on the review date, published scores, then screens, selection, solver constraints re-checked in code, and the PAB/CTB path.

11 · R&D Lab · Replicate

Strategy replication backtests a paper’s claim

A person pastes the paper and approves Claude’s spec; numpy backtests it, and the verdict rests on significance and matching the paper’s return.

12 · Workspace 2 · Argus

Extract cited data points, then score them

Claude extracts, a second, different Claude model verifies, and grounding re-checks every citation. XBRL facts are used first.

13 · Workspace 3 · Transition Intelligence Platform

Monitor holdings and climate transition risk

Every alert gets an owner. Emissions metrics are computed in code and shown in Superset.

14 · Workspace 4 · StewardIQ

Engage companies, vote, report to clients

Rule tables propose; people confirm tiers, approve outreach with a second pair of eyes, and decide every vote.

15 · Workspace 5 · Data Hub

One issuer per security, for the whole tool

Holdings match the security master exactly. Anything unmatched is fixed in the master, never in the holding.

16 · Standing agents

The Taxonomy Researcher proposes, never applies

It re-searches sources for each ratified taxonomy and writes a DRAFT version only when the merge adds activities.

17 · Standing agents

The Calibration Agent flags stale verdicts

A timestamp comparison with no LLM call: newer documents than a verdict raise a drift flag for a person.
