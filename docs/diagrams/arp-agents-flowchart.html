Flowchart · backend/arp/agents

How the agents propose work for people

Both agents run the same way: an API call or the CLI creates the run and gets a run_id straight away, then the slow scan runs in the background. An IntervalScheduler can also fire them on a timer. Neither one changes anything by itself. Its output waits for a person.

Agent 1 · taxonomy_researcher.py

Taxonomy Researcher

Runs once for each ratified taxonomy, one at a time. If one taxonomy errors, the run counts it as failed and moves on to the next.

Agent 2 · calibration_agent.py

Calibration Agent

Runs once for each completed theme run. It only compares timestamps and makes no LLM call. If a source run errors, the run counts it as failed and moves on to the next.
