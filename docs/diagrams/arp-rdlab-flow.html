Overview

R&D Lab end to end

Two processes: launching a thematic product (top row) and researching a strategy (bottom left). Two standing agents propose taxonomy drafts and drift flags. The diagrams below open each stage.

Spot

Emerging Themes

A manual or weekly run. It ends early if there are no mentions, fewer than 3 tags or no clusters. Only BIRTH clusters go on; growth, splits, merges and deaths are recorded only. Run files and topic state stay on disk.

Define

Taxonomy Library

Nine derivation methods; every new taxonomy and version starts as DRAFT, and the only transition is DRAFT → RATIFIED. Versions are files under taxonomies/. Ratifying needs only the analyst role, and theme runs accept DRAFT taxonomies unless ARP_REQUIRE_RATIFIED_TAXONOMY is on (off by default).

Match

Thematic Universe, per company and activity

A LangGraph graph runs for every company × activity, 8 companies at a time by default; each company commits in one transaction, and a resumed run skips finished companies. Sector codes chosen by Claude also go to review.

Score

Decision Studio

No LLM calls. Frameworks are versioned files under frameworks/; a published snapshot can never be overwritten.

Construct

Index Construction

Calibrations are effective-dated versions under indices/calibrations/. Without the optimize extra, or when a solve fails verification, constraints fall back to the capping waterfall.

Replicate

Strategy Replication

Papers are never fetched automatically: a person pastes the text. Deflated Sharpe and PBO are reported but never change the verdict.
