Architecture review · Agentic Research Pipeline · 2026-10-28

Scope: the 216 commits in the clone, hot spots first. The 2026-10-11 review covered db/ and the run store; this one covers the extraction pipelines, run launch, API and CLI assembly, and the frontend data layer. ADR 0001 (importer keeps its own fact rules) is untouched by every candidate.

Each run type wires its own step sequence, launch path and frontend polling; deepening those modules removes most of the repeated work in recent commits

  • Health: the core seams hold. ground_citations has 32 call sites in 21 modules, every LLM call goes through one protocol method (llm/base.py:40), and HTTP errors are handled once in client.ts:159. The friction sits one level up, where each run type assembles its own copy of the sequence around those seams.
  • Biggest friction: one per-company extraction feature lands in 4 to 6 places. Tracing went in at 4 write sites and 6 entry builders with 3 trace shapes. Corrections reached 1 of 5 document pipelines.
  • First move: route every grounding roll-up through ground_claim (effort S). Today 8 copies of the rule give 3 different answers for a claim with no citations, and the engagement dossier counts an uncited claim as grounded.
