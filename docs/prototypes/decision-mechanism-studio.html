The mechanism, derived and open to edit

Correlated indicators are grouped into dimensions so three ways of saying the same thing do not earn three times the weight. A dimension's weight follows the square root of how many criteria it holds; criteria then split it evenly.

Decisions run in a fixed order, so results are reproducible

Sufficiency first, then hard gates, then the score band, then modifiers. Anything a gate settles never reaches the score — a knockout is a decision, not a deduction.

Modifier
Stops a single strong dimension from carrying an entity that fails elsewhere. Applied only to dimensions measured by two or more criteria, so one yes/no answer cannot demote on its own.
