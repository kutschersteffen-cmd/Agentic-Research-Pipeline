# UI polish 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the 11 fixes the owner picked from the new-UI critique, as one PR.

**Architecture:** Each fix is small and self-contained. They are grouped into four tasks by the area they touch: identity, the
shell, workspace and Argus pages, and hub titles. Pure logic changes (`tiles().tone`, `failedProcesses`) get unit tests. Everything
the user sees gets an e2e row.

**Tech Stack:** React 19 + TS, `node --test` source and pure-function tests, pytest + Playwright e2e.

**Spec:** `docs/superpowers/specs/2026-11-15-ui-polish-1-design.md` (AC-1 to AC-11b).

**Starts from:** `main` after PR #484 merges.

## Global Constraints

- Copy, exactly as the spec gives it:
  - "Signed in as {name} ({role})"
  - "Every workspace at a glance"
  - "Passes on:"
  - "Last run failed: <title>."
  - "Open Run history →"
  - captions `N process` / `N processes`
- Amber only for waiting. Failed uses `--low`.
- No colour token or font change. Use `--text-xs`, `--muted`, `--low` and `--s-1_5`.
- The reviewer store key is `arp.reviewer`.
- Every changed or retired test is listed in the PR.

## Review Focus

- **Signing out after signing in.** The reviewer store keeps `me.name`, and the "Reviewing as" field reappears pre-filled with it,
  not empty. Test: Task 1, `test_reviewer_field_returns_after_sign_out` (stub `/api/me` 401 after load, open the menu, the field's
  value is `dev`).
- **Workspace with both a waiting and a failed process.** The failed line shows even though the card's tone is `wait`. Test: Task
  3, `pol_failed_with_wait` (`failedProcesses` returns the failed title while another process waits).
- **Very long `purpose` text in the Workspaces menu.** It wraps inside the 280px popover and never widens it. Test: Task 2, e2e
  menu width stays 280px (±1) at 1440 and at 390.
- **Row alignment between 761 and 1248px.** The formula must not push the first link left of the 32px gutter. Test: Task 2, e2e
  AC-3 also at 900×900.
- **Argus tiles with zero runs.** `tone` is `null`, with no empty failed styling. Covered by AC-7's no-note case.
