Top bar on every page

  • The same bar as the start page, plus "Workspaces".
  • No sidebar, drawer or phone bar anywhere.
  • Review Queue, Reports: underlined when you are on them.

Workspace row

  • Only inside a workspace: its name, then its screens.
  • The current screen is underlined; the row scrolls sideways on a phone.
  • Replaces the "Start › StewardIQ" breadcrumb and the Screens chips.

Shared parts (PR 2)

  • Process state: 8px square + word, as on the cards.
  • Run status: square + word instead of an outlined pill; running is blue.
  • Workspace header carries its drawing.

Process flows (PR 3)

  • A track fills up to the last finished step.
  • Running step: blue edge, pulsing square. Waiting: amber edge.
  • Click a step: its details and an "Open" button. Esc closes.
